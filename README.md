# SigMod Client (Sigmally Mod)

SigMod is a free mod and userscript for Sigmally.com. It adds powerful macros, a live party minimap, custom themes, skins and a bunch of other quality-of-life features to enhance your gameplay.

If you're looking for an auto-feed macro, custom UI themes or a way to play and chat with your friends using a live minimap, this script has you covered.

> **Note:** Sigmally is an Agar.io private server. SigMod is developed exclusively for Sigmally and does not work on the official Agar.io game.

---

## Features

### Sigmally Macros

Take full control of your gameplay with keyboard and mouse macros:

- **Rapid Feed:** Adjustable auto-feed speed for perfect teaming.
- **Split Mechanics:** Double split, triple split, quad split and instant splits.
- **Trick Splits:** Double trick, self trick and line splits (horizontal, vertical, fixed).
- **Quality of Life:** Auto/instant respawn hotkeys and configurable mouse button macros.

### Party Minimap & Social Features

Playing with other SigMod users unlocks exclusive party mechanics:

- **Live Party Minimap:** See your friends' exact positions in real-time.
- **Map Pings & Location Sharing:** Coordinate attacks and retreats instantly.
- **Party Chat & Panel:** Communicate securely with your tag without leaving the game.
- **Friends System:** Send friend requests, view online status, check profiles and send private messages.

### Custom Skins, Themes & Visuals

Completely overhaul the Sigmally client to match your style:

- **Custom Graphics:** Modify cell colors, food colors, borders, maps and viruses.
- **Skins & Text:** Upload custom skin replacements, gradient names, custom fonts and name colors.
- **UI Themes:** Choose from built-in preset themes or build your own with custom backgrounds and gradients.
- **Menu Customization:** Fully style the Sigmally menu and input fields.

### Extra Utilities

- **Daily Rewards:** Automatic daily coin claiming.
- **Gameplay Stats:** Track your performance with the play timer and gameplay statistics.
- **Media Tools:** Image capture, gallery and saved image downloads.
- **Quick Access Menu:** Search for settings, keybindings and tools instantly.

## Installation Guide

Installing the mod is quick and easy. You just need a standard userscript manager for your browser.

1. Install **[Tampermonkey](https://tampermonkey.net/)** (Recommended) or **[Violentmonkey](https://violentmonkey.github.io/)**.
2. **[Install SigMod on Greasy Fork](https://greasyfork.org/scripts/454648)**. The script will automatically update when new features are released.
3. Open [Sigmally.com](https://sigmally.com) and the mod will load automatically.

> Need help? Check out the complete **[SigMod Installation Guide](https://sigmally.xyz/guide)** for step-by-step browser instructions and Tampermonkey Developer Mode setup.

## How to Use SigMod

Once installed, you can open the SigMod configuration menu by:

- Pressing the **V** key on your keyboard.
- Clicking the **gear icon** on the main Sigmally screen.

From here, you can customize your macros, visual settings, name presets, themes, gallery and friend list.

## Frequently Asked Questions (FAQ)

### What is SigMod?

SigMod is a third-party userscript for Sigmally.com. It acts as a custom client that adds advanced macros, a live minimap, cosmetic customizations and social features to the game.

### Is SigMod a bot or a hack?

No. SigMod does not provide bots, invincibility or server-side hacks. It is a client-side extension that adds UI improvements, macros (like rapid feed/split) and custom visuals.

### Does it work with Tampermonkey?

Yes! Tampermonkey is the recommended extension to run SigMod. See the **[installation guide](https://sigmally.xyz/guide)** if you need help enabling Developer Mode in your browser.

### Is this an Agar.io mod?

No. While Sigmally is an Agar.io private server, SigMod's code is specifically built for Sigmally's custom engine. It will not work on vanilla Agar.io.

### Is it free?

Yes. SigMod is 100% free and open-source. The code is publicly available on GitHub under the MIT license.
